## Objetivo

A atividade foi realizada com o objetido de trabalhar a transpilação (Processo de converter código-fonte de uma linguagem para outra linguagem de nível semelhante ) para garantir a compatibilidade do JavaScript com 
a maior quantidade possível de navegadores e dispositivos utilizando Presets do Babel (Conjunto pré-configurado de plugins utilizados para transpilar o código-fonte de JavaScript para determinada versão do ECMAScript).

## Tecnologias Usadas

- **Babel**: transpilação do Javascript;
  
## Técnicas e fundamentos desenvolvidos

- Transpilação;

## Uso

Você pode digitar npm run build no terminal do Visual Studio Code para ver o output do código já transpilado.
